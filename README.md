# bg3-cheat-sheet
A small self sufficient Baldur's Gate 3 cheat sheet inspired by Dark Souls cheat sheets. It is not recommended for first time players.

The checklist is _non-extensive_ and will only include items I feel require mentioning.

To view the cheat sheet [click here](https://encarvlucas.github.io/bg3-cheat-sheet/).

Feel free to help by opening up a Pull request.
